# Un compte désactivé n'est jamais effacé

Quand un salarié part, son compte est désactivé, jamais supprimé : ses
pointages sont un document de travail, et un relevé de paie doit pouvoir
expliquer une heure de l'an dernier. La suppression d'un compte n'existe donc
pas dans l'application.

La règle inverse s'applique aux pointages : un pointage faux — un double
scan, une erreur de tap — est supprimé, parce que ce n'est pas une trace de
travail mais une erreur de saisie. Supprimer un compte pour se débarrasser de
ses heures serait, lui, une falsification.
